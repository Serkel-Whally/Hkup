# Changelog

All notable changes to Whally will be documented in this file.

## [2.0.0] - 2026-07-29

### Added
- Full-stack e-commerce platform
- Backend API with Express.js and MongoDB
- Next.js 14 frontend with TypeScript
- JWT authentication with role-based access
- Stripe and Paystack payment integration
- Multi-language support (English, Twi, Hausa)
- PWA support with service worker
- WCAG 2.1 AA accessibility compliance
- Docker Compose for local development
- GitHub Actions CI/CD workflows
- Email notifications via SendGrid
- Redis caching layer
- Admin dashboard endpoints
- Comprehensive documentation

### Removed
- WhatsApp integration
- Static HTML files (migrated to Next.js)
- Simple script.js (replaced with React)

### Changed
- Redesigned UI with Tailwind CSS
- Improved performance with SSR
- Enhanced security with rate limiting

## [1.0.0] - 2026-07-29

### Added
- Initial static website
- Mobile data bundle plans display
- WhatsApp contact integration (deprecated)
